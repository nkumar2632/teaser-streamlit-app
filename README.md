# Football Teasers v1.0 — local Streamlit app

A mobile-first local interface for the immutable [Teaser Model v1.0](https://github.com/nkumar2632/Football-Teasers-v1.0). NFL teasers use the model's LIVE proposal path; CFB teasers use its full PAPER path. Each view shows league, bet type, model version, and operational status. Enter actual observed 2-team/3-team 6-point teaser prices for EV and selection. Nothing here places a wager.

## Run locally

From `/Users/Nitin/Developer/teaser-streamlit-app`, the existing local environment can run:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/streamlit run app.py --server.address 127.0.0.1
```

Open `http://127.0.0.1:8501` on this computer. The server is bound to loopback, not the LAN. To recreate the environment later, use Python 3.12: `python3.12 -m venv .venv`, `.venv/bin/python -m pip install -r requirements-dev.txt`, then `python3.12 scripts/setup_model.py` to clone or verify the disposable pinned source. The setup script refuses to overwrite a dirty or mismatched existing checkout. Network access is used for the specified GitHub clone, normal dependency installation, and user-triggered public ESPN imports.

## Enter a slate

1. Select **NFL · LIVE** or **CFB · PAPER**. Set season, week, sportsbook/source, and capture time as ISO 8601 with an explicit UTC offset. Enter only observed American teaser prices (`-110`, `+170`); leave unobserved sizes blank.
2. Add one quoted side per observed line, with signed spread, game total and timezone-aware kickoff. NFL uses canonical team choices; CFB accepts college names. Add the opposing side separately when observed. CFB also requires a pregame provenance label. Current and timestamped CFB captures must precede kickoff.
3. Build the card. NFL shows the live proposal and recheck workflow. CFB shows a **PAPER — NOT REAL MONEY** hypothetical selection, qualifying and excluded legs, all constructed tickets, market transcription, offered price, P_ticket, break-even, EV, and hypothetical exposure. CFB final scores can be recorded after the run is frozen; settled paper tickets and cumulative paper units appear in the paper history.

You can import/export bounded JSON slates. Version-1 NFL slates remain supported; version 2 adds league and provenance. **Load verified Week 2 historical example** runs the original NFL sportsbook snapshot unchanged. The original pinned CFB paper artifact remains readable in the CFB history section. A current NFL proposal enters live accounting only when the operator explicitly records a selected ticket as placed after a validated recheck. Historical proposals are never assumed placed. CFB paper outcomes never become live placements or live bankroll units.

## Review results and settlement

Open **Results · review and settle stored cards** to fetch ESPN NFL/CFB scores by date or season/week, or enter final scores manually. Review the editable scores and event matches before **Confirm Results**. Ambiguous matches and conflicting confirmed finals need explicit resolution; older ESPN captures cannot silently replace later manual corrections. Each confirmation is an immutable local result snapshot with source URL and review changes. Reconfirming the latest unchanged result does not duplicate it or double-count performance.

CFB selected tickets are graded as hypothetical PAPER results from their stored lines. For NFL, only explicitly recorded PLACED tickets appear in the settlement view. ESPN scores propose the model result, while realized LIVE profit/loss requires the operator to confirm the sportsbook's actual settlement. Stored placement terms include ticket legs, rechecked price, stake, capture and placement times, and card/market IDs. Pushes or incomplete terms require review. Season totals keep PAPER hypothetical units separate from operator-reported LIVE placements and confirmed LIVE settlements.

## Import public reference lines

Open **Public Lines · fetch and review ESPN**, paste a public [ESPN NFL scoreboard](https://www.espn.com/nfl/scoreboard) or [ESPN college-football scoreboard](https://www.espn.com/college-football/scoreboard) URL, then select **Fetch Lines**. Dated and week-style scoreboard links are supported. The app reads ESPN's public scoreboard JSON; the standalone odds page may require JavaScript verification and is not supported. VegasInsider URLs are not supported yet.

Review the editable table, especially missing or malformed fields, displayed book, and kickoff. Make corrections, then select **Confirm Market Snapshot**. Fetching alone writes nothing. Confirmation saves a new, immutable **REFERENCE** snapshot with the original URL, ESPN fetch URL, capture time, source event IDs, displayed book, and any corrections. Confirmation itself does not build a card or record a placement. No teaser payout is inferred from a reference page.

For Saturday CFB, choose **CFB · PAPER** and **Public lines**, select the confirmed snapshot, review usable and excluded games, then click **Use this slate for proposal** and **Build PAPER card from public slate**. The app creates both quoted sides per usable game; no side re-entry is needed. Already-started, duplicate, conflicting, and malformed games are excluded with reasons. The card builds without teaser prices; missing 2-team/3-team prices can be entered beside the selected slate later. The card names the public line source and the teaser-menu book, which defaults to `bluecoins.ag`. This route is always PAPER and has no placement control. Manual CFB entry remains available as a fallback.

For NFL, choose **Saved market snapshot** after confirming either public lines or a sportsbook screenshot. Review the saved slate, click **Use this slate for proposal**, then **Build proposal from saved NFL slate**. Both quoted sides are generated for each usable game. Missing 6-point teaser prices can be entered without re-entering sides. An ESPN **REFERENCE** card is screening only, even when a separately observed `bluecoins.ag` menu makes EV available. A confirmed sportsbook **EXECUTION** snapshot remains an unplaced proposal. To report an outside placement, select a newer confirmed EXECUTION snapshot from the same book, perform the model recheck, and use the existing explicit placement form only while the recheck and required menu observations are fresh. Reusing an old menu does not refresh it; the separate **I verified these teaser prices are unchanged now** action saves an append-only observation with the book, both prices, source snapshot and new timestamp. Manual and legacy input remain available for proposal review but do not grant execution status.

**Fetch ESPN NFL** and **Fetch ESPN CFB** target the next NFL Sunday or CFB Saturday. To fetch another date, choose **ESPN league** and **ESPN scoreboard date**, then select **Fetch ESPN Lines**. You can still paste a supported URL. Every fetch control uses the same review and confirmation gate, and the saved snapshot retains the exact dated source URL. **Compare reference vs my sportsbook** lets you select stored snapshots for the chosen league. It defaults to the newest execution snapshot and a reference snapshot from the same season/week when available. Matched games show both sides' spread, spread price and moneyline, plus total and literal point differences (execution minus reference). Capture times, stale warnings, missing values, and unmatched or ambiguous games remain visible. This read-only view makes no betting recommendation and never substitutes reference data for actual sportsbook input.

## Import sportsbook screenshots

Open **Import my sportsbook screenshots**, enter the sportsbook, league, and capture time, then upload up to six PNG or JPG screenshots. Select **Extract Lines**. On macOS the app first attempts local Apple Vision text recognition; if it is unavailable, the same screen provides a manual recognized-text and editable-table fallback. No cloud vision service or credential is used.

Review the recognized text, merge results, uncertainty/conflict flags, kickoff, every quoted market, and the separate standard 6-point teaser prices. Overlapping screenshots may add complementary fields to one game. Conflicting lines are left blank and must be resolved; 10-point and 13-point products are never mapped into the 6-point fields. Select **Confirm EXECUTION Snapshot** only after correction, or **Discard screenshot preview** to save nothing. Confirmation creates a new immutable `EXECUTION` market snapshot that works with the existing reference comparison. It does not build a model card, change LIVE/PAPER accounting, or place a wager.

Images are validated and processed in memory, with a short-lived private temporary file used only by local Apple Vision. Raw images are deleted rather than retained. The saved snapshot records filenames, dimensions, byte sizes, upload times, SHA-256 hashes, extractor name, warnings, and user edits. OCR is a convenience and can misread sportsbook layouts; ISO kickoff recognition is deliberately conservative, and the operator must fill or correct missing values before confirmation.

## Boundary and limitations

`app.py` → display records/formatters in `teaser_app/` → `TeaserModelAdapter` → the actual source package in ignored `.model_reference/src`. Only the adapter imports the model. The adapter invokes source CFB paper grading, pricing, ticket construction, selection, and outcome grading; no teaser formulas are copied into the app. Strategy identity is a four-part record (`league`, `bet_type`, `model_version`, `status`), leaving ATS/ML and CHALLENGER as future configurations without implementing those models. The pin is `94e412ed5bedc03a60b0b86f1146ff80c9f9e195`. See [MODEL_PIN.md](MODEL_PIN.md), [SECURITY.md](SECURITY.md), and [market snapshot schema](market_data/schemas/market_snapshot_v1.md).

Manual and confirmed URL-reference market snapshots, menu verifications, CFB paper runs/results, confirmed game results, and operator-reported NFL placements/settlements are append-only local JSON in `market_data/`. The files are ignored by Git and older records remain individually retrievable. New manual snapshots with identified `manual_sportsbook` provenance are marked `EXECUTION`; uncertain old records remain unclassified and excluded from comparison rather than guessed. The app never rewrites historical source artifacts in `.model_reference/`. Paper performance is calculated only from settled hypothetical selections and is separate from real-money accounting.

This is a local workspace with on-demand public ESPN fetching and review-gated local screenshot transcription, not a live odds feed, sportsbook account, certified placement gate, or public deployment. ESPN's public response shape and availability can change; a failed fetch leaves stored data unchanged. Screenshot OCR is not authoritative and cannot reliably infer cropped headings, arbitrary date formats, or a sportsbook identity. Real sportsbook screenshot/OCR browser QA and the unavailable Claude golden pack remain local checks. NFL placement and sportsbook settlement records are operator reports, not verified sportsbook receipts; unsaved form edits remain session-only. Public CFB team names use ESPN's school location when supplied, otherwise the reviewed display name; unresolved aliases still need local review. CFB teaser prices and final scores are manually reported, so paper performance is only as accurate as those inputs. No price means no EV or hypothetical selection for that ticket size. Secondary research is never promoted into the card. NFL recheck does not validate all placement conditions. Independently verify prices, scores, and settlements before making any outside decision.
