# Local security boundary

- Only this app workspace and its disposable `.model_reference/` checkout were used. The app does not search personal folders or unrelated repositories. The model reference is ignored by the app Git repository, pinned to `94e412ed5bedc03a60b0b86f1146ff80c9f9e195`, checked for changed/untracked/ignored source files and foreign preloaded modules, and has its push URL set to `DISABLED`. The app never edits source-model files.
- Streamlit binds `127.0.0.1`, keeps CORS/XSRF protection enabled and disables usage statistics. There is no public deployment, sportsbook credential flow, account integration, scraping, odds API, or automated wager placement. The only required outbound access during setup is the specified GitHub repository and standard Python packages; normal grading makes no app network calls.
- Market snapshots, paper runs, and paper result revisions are append-only local JSON in ignored `market_data/` folders. Imported slates cannot specify filesystem paths; record retrieval accepts only generated IDs. CFB final scores join a frozen model run after selection and never enter the source placement ledger or live bankroll totals. Local history files contain user-entered sportsbook data and should remain on this computer.
- No secrets are required. `.env*`, `.streamlit/secrets.toml`, keys and similar local files are ignored; never put credentials into a slate or source-control files. A downloaded slate contains whatever sportsbook metadata you entered, so handle it as your own local data.
- Manual/JSON inputs are bounded and validated. JSON is parsed as data, with duplicate fields rejected. There is no `eval`, pickle/deserialization, shell command built from user input, arbitrary user-selected file path, or upload persistence. User text rendered in HTML cards is escaped. Model source files are read from fixed paths only.
- **Residual limits:** The user must verify that manually entered lines, prices, timestamps and final scores are accurate and pregame where claimed. The app has no authentication or certified placement ledger and should remain on loopback. Local history files are append-only but not protected against someone with filesystem access. Recheck is not the model's full placement authorization. A **PLACED** label is an unverified, temporary operator annotation, not evidence that a wager was made. Third-party Python packages are installed from the standard registry; update them deliberately and rerun focused contracts. One upstream source test rewrites a tracked report timestamp; do not run the source's full suite in the pinned reference. See MODEL_PIN.md for recovery history.
